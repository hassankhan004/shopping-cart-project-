# House of Gaming Nerds 🎮

**House of Gaming Nerds** is a console-based Python shopping system for gaming consoles and accessories. It features admin product management, user cart handling, and purchase history.

## Features

- 🧑‍💼 Admin Login with Add/Remove/Update product features  
- 👥 User Signup/Login system  
- 🛒 Add to Cart, Remove from Cart, View Cart  
- 💾 Save/Load Cart  
- 💰 Checkout with purchase history  
- 📅 View History by Date or Item  

## Tech 
- Python
